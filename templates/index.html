Use this tool directly from your terminal, integrate it in Python scripts, or invoke the REST API.

1. CLI Usage 
# Download photos from a post
python scrape_instagram_photos.py --query "https://www.instagram.com/p/DFzL121P0qG/" --download

# Scrape profile photos and export JSON
python scrape_instagram_photos.py --query "@natgeo" --max-posts 15 --format json --output natgeo.json

# Launch the live Web UI
python scrape_instagram_photos.py --serve --port 5000
2. Python Package Integration 
from scrape_instagram_photos import InstagramScraper

scraper = InstagramScraper(config={"download_dir": "./my_photos"})
results = scraper.scrape("https://www.instagram.com/p/DFzL121P0qG/", download=True)

for res in results:
    print(f"Author: @{res.username} | Likes: {res.likes:,}")
    print(f"Photos: {len(res.media_urls)} found")
